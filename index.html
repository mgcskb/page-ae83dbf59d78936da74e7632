猪云

猪云官方网站面向需要稳定跨境访问的个人与团队，提供机场订阅、VPN 客户端与网络加速说明。页面集中介绍套餐对比、使用场景与客户端下载路径，方便你在官网完成选型后再导入常用工具。

猪云把线路整理、订阅下发和多端接入放在同一套流程里：先按流量与设备数选择套餐，再在客户端填写订阅地址，即可用于办公会议、学术检索、流媒体点播和游戏加速。

品牌简介

猪云是网络加速与机场订阅服务品牌，强调可预期的带宽、清晰的流量账单和可同时在线的设备配额。官方站点不捆绑复杂账号体系，重点说明如何把订阅导入 Windows、macOS、Android、iOS 与常见开源客户端，降低第一次配置的时间成本。

在节点策略上，猪云区分普通线路池与更高优先级的专线资源。基础版覆盖日常网页与基础流媒体；旗舰版增加原生流媒体解锁与 IPLC 游戏向优化；团队版面向工作室和小型企业，提供更高流量上限、更多同时在线设备以及可协商的路由策略。

服务边界

猪云定位为加速器与订阅分发，不代替本地杀毒、企业防火墙或合规审计。请仅将服务用于合法的跨境办公、内容访问与延迟优化。账号请勿转售或共享超出套餐设备上限，以免触发限速或临时锁定。

使用场景

跨境办公与远程协作

猪云可用于访问海外文档、代码托管、设计协作与视频会议。建议对会议软件单独分流，避免把全部国内流量送入加速通道。旗舰版与团队版在晚高峰仍保留可用带宽余量，减少共享会议室卡顿。

流媒体与内容检索

基础版覆盖常见点播与资讯站点；旗舰版强调全节点原生解锁，降低地区版权提示。学术检索、公开课与软件文档同样适合走加速节点，本地更新与网盘大文件建议保持直连以节省套餐流量。

游戏与实时对战

游戏加速依赖专线稳定性多于单纯高带宽。旗舰版标注 IPLC 向优化，适合对延迟抖动敏感的对战与登录器。请在客户端为游戏进程开启规则模式，而不是全局模式，以免语音软件与启动器一并绕行。

操作说明

  1. 在官网选定基础版、旗舰版或团队版，完成订阅后进入用户中心复制机场订阅链接。链接请视为密钥，不要发到公开群组。
  2. 打开本页「客户端下载」对应系统的官方入口说明，安装桌面或移动端客户端。系统代理权限需按系统提示授权，否则浏览器不会走加速。
  3. 在客户端选择「从 URL 导入」或「订阅」，粘贴猪云提供的订阅地址并更新节点列表。首次导入后建议手动测速，收藏延迟更低的入口。
  4. 将模式改为规则分流：国内网站直连，跨境办公与流媒体走代理。确认设备数未超过套餐上限后再打开第二台设备。
  5. 若出现无法解锁或握手失败，先更新订阅、切换同一区域的备用节点，再提交工单并附上客户端日志时间戳。旗舰版与团队版走优先队列。

流量与设备注意事项

视频、系统更新和云同步最消耗流量。可在客户端排除系统更新域名。同一账号在超出同时在线台数时，最早接入的会话可能被踢下线。团队版如需固定出口 IP 或按部门拆分订阅，通过客户经理提交路由需求即可。

常见问题

猪云是什么？和普通加速器有何不同？

猪云是提供机场订阅与多端接入说明的网络加速品牌。它把流量配额、同时在线设备和线路分级写进套餐，而不是只给单一全局加速开关。用户在官网完成选型后，用通用客户端导入订阅即可，便于在办公、流媒体和游戏之间切换规则。

如何从官网完成客户端下载并导入订阅？

先在本页「客户端下载」确认系统类型，安装对应客户端并授予代理权限。登录猪云用户中心复制订阅 URL，在客户端选择从 URL 更新。导入成功后应能看到节点分组。不要使用来路不明的安装包，以免订阅被劫持。

基础版、旗舰版和团队版该怎么选？

基础版每月 100GB、3 台设备，面向轻度访问。旗舰版 300GB、5 台设备，带原生流媒体与 IPLC 游戏向优化，是官网主推档。团队版 1000GB、20 台设备，带 VIP 节点、定制路由和客户经理，适合多人共用。年付分别对应 ¥150、¥350 与 ¥850，适合已经确认会长期使用的用户。

流量用尽或设备超限会怎样？

流量在计费周期内累计，用尽后加速通道会限速或暂停，直至升级套餐或进入下一周期。同时在线超出配额时，新设备可能无法握手。建议在客户端查看已连接终端，关掉长期挂机的旧会话。视频缓存和大文件同步请尽量直连。

猪云能否用于游戏加速和视频会议？

可以。游戏建议使用旗舰版标注的专线节点，并采用分应用规则，只让游戏与登录器走代理。视频会议同样建议独立规则，避免桌面共享把局域网打印机流量带出。若持续丢包，优先更换同区域节点而不是反复开关客户端。

支持哪些系统？是否必须使用指定软件？

Windows、macOS、Android、iOS 与常见 Linux 发行版均可。猪云下发标准机场订阅，兼容多数支持订阅更新的客户端。没有强制专有 App；只要客户端能解析订阅并更新节点，即可作为猪云 VPN 接入方式。网关或软路由用户可用团队版做集中分流。

工单如何提交？旗舰版优先体现在哪里？

在用户中心提交工单时请写清系统版本、客户端名称、订阅更新时间和问题截图中的报错原文。旗舰版享有 7x24 优先队列，适合线路突发与解锁异常。团队版另配客户经理，可讨论固定出口、分部门订阅和企业定制路由，而不是只处理单点故障。
